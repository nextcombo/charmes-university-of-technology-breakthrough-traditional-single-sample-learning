✿Title: Single-Sample Learning Modulation Format Identification in the Evolution of Optical Networks  
Abstract: This paper successfully applies a single-sample machine learning approach for the first time, capable of recognizing new modulation formats with just one constellation diagram without retraining the model. When the supported modulation formats were expanded from two to five, the approach still achieved 100% recognition accuracy.  
Introduction: In the continuously evolving optical networks, coherent receivers need to quickly adapt to transmission parameters (such as modulation format and bit rate) to cope with changes in network conditions. Without prior knowledge of the transmitter settings, modulation format identification (MFI) allows receivers to adjust their digital signal processing algorithms in real-time, thereby reducing the requirements for optical performance monitoring and control message interactions in software-defined optical networks. In recent years, machine learning (ML) has shown potential in multiple MFI applications, especially convolutional neural networks (CNN) within deep learning (DL) models, which have achieved high accuracy in the task of modulation format identification through analyzing visual representations of optical channels (such as amplitude histograms, eye diagrams, constellation diagrams).
However, existing deep learning-based modulation format recognition models face two major challenges when introducing new modulation formats: firstly, the process of collecting and labeling a large training and validation dataset is time-consuming, expensive, and energy-intensive; secondly, it requires complex retraining of machine learning models, or even the need to redesign them. Since convolutional neural network parameters (such as layer numbers, neuron counts, filters, activation functions) are optimized for specific sets of modulation formats, existing convolutional neural network architectures may not be able to classify new modulation formats. For example, a convolutional neural network trained for 2 modulation formats (4-bit and 16-bit quadrature amplitude modulation (QAM)) needs to add new categories and retrain when introduced with 64-bit QAM, which could take several hours or even days, severely limiting the flexibility of the network in introducing new modulation formats.
To address this, this paper proposes for the first time a Siamese Convolutional Neural Network (Siamese CNN) based on Single-Sample Learning (OSL) for constellation diagram modulation format recognition, aiming to solve the shortcomings of existing deep learning-based modulation format recognition models. This method does not require retraining or redesigning models when introducing new modulation formats, laying the foundation for seamless adaptive machine learning models in evolving optical networks. The single-sample learning model trains on a set of known constellation diagrams for each modulation format, learning the similarity between graph pairs; after training, even when faced with a modulation format not present in the training data set, the model can evaluate the similarity between any two constellation diagrams by only having one sample example of each modulation format.
Method Overview: Traditional convolutional neural networks (as shown in Figure 1(a)) learn to extract relevant features at the initial (leftmost) layer and finally learn to map these extracted features to specific categories (which in this case represent modulation formats), outputting the probability that an input sample belongs to each category. In contrast, single-sample learning adopts a different approach (as shown in Figure 1(b)), focusing not on learning feature extraction and its association with various categories but on learning a similarity function.
The training dataset for single-sample learning consists of multiple pairs of constellation diagrams, each pair marked with the same modulation format (similarity score of 1) or different modulation formats (similarity score of 0). During training, the parameters of the convolutional neural network are iteratively adjusted to match the model output with the true similarity scores of the input constellation diagram pairs. In the inference phase, the convolutional neural network receives a single sample and generates its probability of belonging to each category, while the single-sample learning model receives a pair of samples and calculates their similarity score. If one of the samples has a known modulation format, the similarity score output by the single-sample learning model can determine whether the unknown input sample belongs to the same category as the known modulation format.
The application process of single-sample learning in modulation format identification is shown in Figure 1(c). Before classification, it only requires an example of the constellation diagram for each modulation format (even if it is a newly introduced modulation format) to initiate the recognition work.
The training dataset consists of 50 examples for each format: orthogonal frequency division multiplexing (OFDM) and square 16-bits orthogonal amplitude modulation, as well as 64-bits OFDM and circular 16-bits/64-bits orthogonal amplitude modulation. The test dataset contains 100 samples per category, with the Nearest Neighbor (NN) algorithm and Random Guess (Rnd) algorithms used as comparative methods. The NN algorithm makes modulation format guesses based on the Euclidean distance between the unknown constellation diagram and the provided example.
Conclusion This paper proposes an efficient modulation format identification single-sample learning (OSL) model suitable for evolving optical networks. The model can identify new introduced modulation formats in real-time and seamlessly without expensive data collection or complex model redesign and training. Furthermore, the model has potential application value in other common classification tasks of optical networks such as bit rate recognition and fault recognition.
